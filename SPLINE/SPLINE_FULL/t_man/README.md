# Исходные ломаные для прогонов Legacy

Каталог [`curves`](curves) содержит синтетические исходные ломаные в том же
формате, что и `testing_data/A146.txt`:

```text
496180.158<TAB>4983238.572
496190.157<TAB>4983238.594
```

В файлах нет заголовка: одна строка — одна исходная точка `X, Y`. Все
координаты записаны с точностью до миллиметра.

## Что меняется между тестами

- Диапазон координат: от локальных координат около нуля до значений порядка
  миллионов метров. Так проверяется, не зависит ли результат от переноса оси.
- Частота съёмки: постоянный шаг от 2 до 20 м либо повторяющийся переменный
  шаг от 2 до 35 м.
- Поперечный шум: от `0` до `3 м`. Это смещение точки по нормали к точной оси,
  а не ошибка отдельно по `X` и `Y`.
- Геометрия: прямые, левые и правые повороты, S-образная ось, несколько
  поворотов, предельные радиусы и диагностические случаи.

Полная таблица длины, числа точек, шага и шума находится в
[`curves/manifest.csv`](curves/manifest.csv).

Первые три файла описывают **одну и ту же ось с одним и тем же началом**:

1. `01_left_dense_clean.txt` — шаг 2 м, без шума;
2. `02_left_a146_step_low_noise.txt` — шаг 10 м, шум до 0,15 м;
3. `03_left_sparse_rough.txt` — переменный шаг 18–35 м, шум до 1,2 м.

Эта тройка отделяет влияние частоты и шума от влияния самой геометрии.

## Назначение файлов

| Файл | Проверяемый случай |
|---|---|
| `01`–`03` | Один левый поворот при разном качестве съёмки |
| `04` | Один правый поворот |
| `05` | S-образная ось: левый, затем правый поворот |
| `06` | Длинная ось из шести чередующихся поворотов |
| `07` | Радиус 2900 м, близкий к типичному `Rmax = 3000 м` |
| `08` | Радиус 260 м, близкий к типичному `Rmin = 250 м` |
| `09` | Между поворотами только 12 м прямой |
| `10` | Хорошо выраженная промежуточная прямая длиной 520 м |
| `11` | Точная проектная ось без шума |
| `12` | Только прямая с переменным шагом и шумом |
| `13` | Файл начинается непосредственно на круговой кривой |
| `14` | Файл заканчивается непосредственно на круговой кривой |
| `15` | Полный угол одного плавного поворота больше `pi/2` |
| `16` | Полный угол плавного поворота близок к `pi` |
| `17` | Шум до 3 м — больше типичного допуска сдвижки 2 м |
| `18` | Скачок направления соседних звеньев на 110°: сообщение `> PI/2` |
| `19` | Скачок направления соседних звеньев на 175°, близкий к `pi` |
| `20` | Короткий шумный зигзаг без устойчивого начального направления |

Значения `Rmin`, `Rmax` и допустимой сдвижки не записаны в этих файлах: это
настройки Legacy, а не свойства формата исходной ломаной. Для случаев `07`,
`08` и `17` надо задать соответственно `Rmin = 250 м`, `Rmax = 3000 м` и
максимальную сдвижку `2 м`, если требуется проверить именно указанную границу.

Колонка `expected_legacy_branch` в манифесте пока описывает назначение теста,
но не является доказанным эталонным результатом. После каждого Legacy-прогона
к файлу нужно сохранить трассу `pech` и итоговый `.e99`; тогда результат станет
эталоном для автоматического сравнения Python и Legacy.

## Повторная генерация

Из корня `python_road_spline`:

```bash
python3 legacy_pech_port/tools/generate_input_curves.py
```

Генератор детерминирован: при повторном запуске создаются те же координаты.
