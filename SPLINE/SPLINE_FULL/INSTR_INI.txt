                                          ИНСТРУКЦИЯ
  1. Данный блок предназначен для ввода и предварительной обработки исходных данных для 
     последующего проектирования плана трассы.На входе имеем ломаную линию, заданную 
      декартовыми координатами её узлов.Для визуализации  эта линия может быть представлена 
     графиком в декартовых координатах или углограммой. Есть возможность переключаться
     с одного представления на другое.
  2.Исходный рисунок может быть представлен в различном масштабе. Масштаб  для соответсвующей
     оси может быть изменен с помощью кнопок 'вверх-вниз'.
    Текущий коэффициент масштаба отражается на поле рядом с кнопками;
  3.Для передвижения по графику ,служит кнопки: "в начало" ,"в конец","сдвиги по шагам".
    При передвижении курсора в нажатом состоянии по экрану в  нужном  направлении,  график 
      перемещается вместе с курсором.
  4.Есть возможность смещения из любого положения в начало или в конец графика при выборе 
     нужной кнопки. Если введены данные на участок большой длины (> 2000 узлов),то для 
     перемещения по графику удобно использовать кнопку "сдвиги по шагам".При этом можно
     выбрать и затем при необходимости переключать направление перемещения "Шаги вправо" и
    при переключении "Шаги влево". Величина шага в километрах задаётся рядос с этим выбором
     и может изменяться как стрелками вверх- вниз, так и непосредственно правкой числа .
    При этом можно задавать шаг  с десятичной точкой, то есть меньше 1 км ( например 0.1)
    Для реализации шага нужно нажать кнопку"сдвиги по шагам". Такие смещения приходится 
    делать при поиске прямых участков в заданной ломаной линии для разбиение её на расчётные
    участки с началом и концом на прямых.
    5.Если щелкнуть левой кнопкой мыши по узлу ломаной, то внизу экрана будет показан радиус
     окружности, соединяющей три смежные узла. Это позволяет увидеть грубые ошибки .
